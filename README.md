# Практична робота №2

Проєкт створено за відповідною практичною роботою з Word/PDF-документа.

## Що реалізовано

- `SequenceBuilder<T>` для збереження і виведення елементів.
- `ChangeTracker<T>` для відстеження зміни значення.

## Git

У репозиторій не додаються `bin/`, `obj/`, `.vs/` і `*.user`.
